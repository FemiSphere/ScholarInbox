# 原始摘要补充与相关性复评（2026-10-22）

正式 DeepSeek 运行默认启用。顺序为：邮件提取 → 去重 → 思考模式初筛 → 高、中相关论文补充原始摘要 → 思考模式复评 → 一次非思考翻译 → 输出。

## 来源与页面

arXiv 优先直接读取官方摘要页并核验 citation ID 与标题，失败再走 DeepSeek Fetch/Search；其他来源优先 Fetch 已有论文链接或 DOI，必要时用 Search 找来源。arXiv 的 PDF/HTML 链接转换为摘要页；支持可信出版方、预印本，以及 PMC/PubMed 摘要库。须通过论文身份核验并提取原始 Abstract。搜索 snippet、summary 只能发现来源，不能当作原始摘要。来源中含有的指令一律视为不可信数据。

原始邮件片段保持不变，补充摘要独立存储。复评可以上调或下调相关性；最终翻译使用补充摘要，并保留证据不足的表述。最终 MD/HTML 沿用原格式，只在已有详情中增加“摘要来源”链接，不展示初评/复评变化或搜索过程。

没有找到可靠摘要、超时、预算用尽或可选复评失败时，保留初筛结果。可选步骤失败不计入核心 API 回退，不阻止正常生成及邮件已读/索引更新；用户取消仍立即传播。核心提取、初筛或翻译失败沿用原有邮件保护。

## 默认运行上限

| 设置 | 默认值 |
| --- | --- |
| 候选论文 | 最多 30 篇，高相关优先，再按得分 |
| 网络总请求数 | 最多 80 次，含 arXiv 直取与 Search/Fetch 重试 |
| 抓取并发 | 最多 3 |
| 单次网络等待 | DeepSeek 12 秒；arXiv 直取最多 6 秒 |
| 每篇等待预算 | 20 秒，避免个别慢站点耗尽所有机会 |
| Search/Fetch 自动重试 | 默认 0；通过切换来源恢复，不重复等待同一慢请求 |
| 抓取阶段预算 | 90 秒 |
| 摘要补充及复评总预算 | 180 秒，不含最终翻译 |
| 复评批量 | 最多 10 篇，串行批次，共享剩余预算 |

API 请求可能产生额外费用，实际用量记录在现有 metrics 日志。预算是等待上限而非成功保证；覆盖率受站点、身份信息及服务延迟影响。未补充成功的论文仍可正常完成本次处理，后续普通运行不会自动重新补充已处理论文。

## 文件与缓存

原始网页、Search 响应及页面清洗内容仅存内存，不创建逐论文 HTML、JSON 或抓取目录。唯一新增的持久运行文件为 `data/cache/web_evidence.sqlite3`，只保存可复用摘要、来源和身份信息，或短期“未找到”记录。

- 最多 300 条、8 MiB；启动/关闭清理过期项并按最近使用淘汰、回收数据库空间。
- 成功摘要保留 30 天；确认未找到保留 6 小时。网络/API 异常不写负缓存。
- SQLite 事务和连接在正常结束、异常及取消路径关闭；不使用持续增长的 WAL 文件。
- 缓存损坏或不可用时跳过缓存，不删除无法识别的已有文件。
- `web_enrichment.cache_enabled: false` 完全关闭磁盘缓存；程序未运行时可直接删除该 SQLite 文件。
- `web_enrichment.enabled: false` 关闭整个补充步骤。

配置示例在 `config.example.yaml`。`abstract_extraction` 使用非思考模式，只辅助从复杂页面定位原文；结果仍须通过原文逐字匹配与摘要区域验证。`paper_ranking` 保持思考模式；`paper_translation` 和邮件提取保持非思考。

## 验证与边界

227 项离线测试通过，包含来源身份、搜索概述隔离、截断、超时、缓存容量/回收、取消、可选异常与最终翻译隔离。样例 dry-run 正常生成 MD/HTML。

第一轮真实 10 篇候选试验中，1 篇出版方摘要完成核验、复评与翻译，其他因超时、缺失或匹配失败保留初筛；临时 SQLite 目录在结束后删除。排查发现 arXiv 实际返回 `Abstract\:`，已修复转义解析和 PDF → 摘要页转换。修复后单次真实 Fetch 从 MOSAIC 取得 1413 字符的核验摘要；未为此重新运行整批。以上验证说明管线可用，不代表所有来源均可抓取，也尚未通过人工标注评估相关性准确率的改善幅度。

## 2026-10-23 稳定性修复

当天 26 篇候选仅取得 2 篇摘要，主要原因是 Fetch 连续超时及重试耗尽 90 秒共享抓取预算，后续 19 篇报告预算耗尽。修复采用官方 arXiv 摘要页直取优先（串行、起始至少间隔 3 秒），每篇共享 20 秒上限，默认不重试同一个 Search/Fetch 请求。所有请求继续受总预算与取消机制约束。

直接来源保持原有身份和原文核验；不放宽匹配阈值，不拿搜索概述补齐论文结论。取得的核验摘要即使复评失败也交给最终翻译，评级保留初筛。旧策略的负缓存不再阻止新获取路径，正缓存仍可复用。逐篇成功/未找到及来源写入现有日志，不增加阅读页信息或逐篇磁盘文件。

真实只读验证：当天缺少摘要的 `2610.23643` 与 `2610.24418` 官方页面均取得摘要；验证未修改 Gmail 或索引、未调用付费 DeepSeek。两次合计约 1.47 秒是在加入请求限速前测得，不能当作整批吞吐保证。站点限流、代理或网络仍可能导致失败。
